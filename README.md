# KeyP: Your Interest Alerts

KeyP는 개인의 관심사를 AI가 찾아서 실시간으로 알림을 전달해주는 서비스야. 오늘 우아한 바톤이라는 해커톤에 참가해서 6시간만에 4명의 풀스택 개발자들과 만들고 있어. 내가 맡은 역할은 세상에 존재하는 모든 SNS(유튜브, 인스타, 페북, 링크드인 등등) 에 접속하고 검색해서 실시간 정보를 분석해 알림을 보낼 수 있는 코드를 짜주고 눈에 보이게 UI/UX도 짜줘. 그리고 다른 개발자들과 공유할 수 있는 형태의 코드로 만들어줘. API 형태로 제공해줘도 될 것 같아.
